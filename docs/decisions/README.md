# Architecture Decision Records

Maintained by the `decision-recorder` agent. One file per decision, numbered sequentially:
`NNNN-<short-title>.md` (e.g. `0001-use-shadcn-ui-for-components.md`). Use [`_TEMPLATE.md`](_TEMPLATE.md).

Decisions are never edited to change their outcome: a new ADR supersedes the old one and both are linked.
