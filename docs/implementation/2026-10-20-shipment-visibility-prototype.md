M12 gate decisions without ADR (user choices, recommended option unless stated): every All shipments row links to `/ops/shipments/:id`, also rows with an open exception, which render the exception layer, an "Exception opened" badge and an "Open in exceptions inbox" link (user choice over keeping M11 links); every action button is a simulated toast, including "Copy customer tracking link" (user choice over a real clipboard copy), "Review AI draft to customer" goes to the exception detail and hides without a pending draft; AI signal uses the design copy (user choice over deriving it), adapted per seed shipment as a seeded `aiSignal` field with that shipment's facts; document check also shown on mobile; seed ids SH-1033 on track / SH-1034 watching / SH-1035 predicted delay; source events sheet wired on this page via `?events=open` through a hook shared with the exception panel; detail alone at full width with a back link keeping the list filters (without `events`); "Exception opened" only when an exception exists in the data (reads never write); non-designed cases reuse existing patterns (other exceptions → exception layer and type badge, stale → "No recent update", delivered → "Delivered", scheduled → "Scheduled").
